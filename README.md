### 保真度校验 `npm run fidelity`

"复刻"不该靠嘴说。`tools/fidelity-check.js` 会以**上游原版提交为基准**（自动取 `git merge-base HEAD master`，可用 `FIDELITY_BASE=<rev>` 覆盖；不是拿 HEAD 自己和自己比）取出原始实现，和当前工作区的实现在**同一颗种子随机数**下跑同样的流程并逐字段对比（用 `mulberry32` 锁死 `Math.random`）：

```
[1] 装备生成器（4 部位 × 5 品质 × 5 等级）        ✓ 200 组 0 差异
[2] 角色属性聚合 store.set_player_attribute        ✓ 60 组随机装备 0 差异
[3] handle.js / 4 份装备 config 与上游 diff        ✓ 全部为空
[4] battle.js 新属性为 0 时与原版竞速解算等价       ✓ 500 组随机战斗 0 差异
[5] 新增玩法：空状态恒等 + 真实增益                  ✓ 逐位一致 / 上阵 3 英雄 ATK 209→1966
[6] 章节远征 / 每日：数值锚点与幂等                    ✓ 13 项（怪物数值仍等于原版中位数）
```

当前输出：`==== 23/23 通过 ====`。

第 4 项尤其关键：新属性（反伤/闪避/吸血…）在取值为 0 时，`resolveBattle` 的胜负判定与伤害必须和原版逐位一致，否则就说明"扩展"污染了基础手感。

第 5 项是双向证明：既要求"英雄/套装/祭坛全为空时结果与原版逐位一致"（恒等），也要求"上阵 3 名英雄后面板必须变强"（防止新系统只写了 UI、其实没接进属性管线）。校验里注入的是 `sets.js / abyss.js / achievements.js / heroes.js` 的**真实实现**而不是桩函数，所以这项证明对线上代码成立。

第 6 项盯的是「新玩法有没有偷偷改曲线」：章节怪物必须仍然等于原版副本怪表的中位数（1-1 关 = lv5「普通」的 543 血 / 73 攻）、扫荡收益必须是 3★ 收益的固定 60%、体力必须按时间戳懒算（离线 1 小时 = +24 点）、每日任务必须"同一天同一批、隔天换一批、进度只算当日增量"、签到必须"连签推进周期 / 断签归位第 1 天 / 一天只能领一次"。这些数字一旦被人改动，校验就会红。

## 2. 新增玩法（新设计）

新增内容全部走"旁路 + 零值即原样"的原则：不进新系统时，游戏就是原版。

### 2.1 套装系统（补完上游的坑）

上游副本面板里写着 `困难，极难下有几率出现套装装备(下个版本加入)`，但作者没做。这里把它实现完：

- 套装**身份来自装备底材本身**（复用原版已有的名字/图标/词条公式），不新增贴图资源；
- 困难 30% / 极难 45% 概率把掉落**定向**到某个套装底材（`createNewItem(q, lv, forceTypeName)`），幸运值再放大；
- 4 个套装，2 件 / 4 件两档：

| 套装 | 2 件 | 4 件 |
| --- | --- | --- |
| 狂战之怒 | 攻击 +12%、暴伤 +15% | 反伤 18%、暴伤 +25%、攻击 +10% |
| 影袭之约 | 闪避 +6%、暴击 +5% | 闪避 +8%、吸血 12%、暴击 +7% |
| 圣殿守卫 | 护甲 +25%、格挡 +15% | 生命 +20%、回血 +60%、护甲 +15% |
| 贪婪之旅 | 金币 +30% | 金币 +45%、幸运 +60、回血 +100% |

### 2.2 深渊回廊（roguelike 新模式）

`src/views/component/abyssPanel.vue` + `src/assets/config/abyss.js`

主世界是"刷装备"，深渊是**局外构筑**：

- 入场时把面板（DPS / 最大生命）拍成**锚点**，之后每层按固定曲线放大：`战斗时长 k=2.2*(1+0.05n)`，`生存难度比 d=4.2*0.955^(n-1)`，于是 `怪物HP = 锚点DPS*k`、`怪物ATK = 锚点MAXHP/(k*d)`。输出与生存两条轴都保留，任何进度进来都能玩，深浅只取决于面板与祝福；
- 每过一层 **三选一祝福**（19 种，普通/稀有/传说，可反复叠加，`贪婪之心` 还能增加选项数）；
- 第 3 层精英、每 5 层首领（击杀回满血）；
- **随时撤退**带走本层累计「回响」，死了只保留 60%（祭坛可升到 100%）；
- 深渊用独立的深渊血量，不动主世界 HP —— 两个模式互不干扰，但收益互通。

实测曲线（`tools/` 里同公式模拟）：裸面板约 14 层，3 级祝福 23 层，坦克向构筑 29 层。

### 2.3 深渊祭坛（永久成长，反馈主世界）

10 项永久强化，`cost = baseCost * costK^lv`：攻击/生命/护甲/金币/幸运/祝福选项数/死亡保留/反伤/离线上限/征战速度。**关键设计**：祭坛加成对主世界同样生效（金币倍率、幸运提高独特掉率与重铸 roll 数、速度加快副本推进），所以"换个模式玩"也能推进本体验，而不是两个互不相干的小游戏。

### 2.4 离线挂机收益（挂机游戏的正字）

上游关掉页面就完全暂停。`src/assets/js/offline.js` 用你自己的刷本曲线反推金币/小时（怪物金币 `lv^1.16*13.5`、单场耗时由 `HP/DPS` 得出），离线效率 45%、上限 8 小时（祭坛 +1h/级），并补算离线回血。存档新增 `ex.t` 时间戳，1 分钟以内不弹（避免刷新页面反复弹窗）。

### 2.5 自动征战

副本面板加一个勾选框：通关后自动重复挑战（普通副本原地刷、无尽自动爬层），**死亡或背包满自动停**。这是把"挂机"真正变成挂机的部分。

### 2.6 成就与称号

16 条成就 → 12 个全局被动称号，**同时只能戴一个**（想换流派的收益就得放弃另一份）；成就顺带给回响，和深渊共用一套通货。成就进度不是装饰：`metric(state)` 直接读运行中的 store，切页即刷新。

### 2.7 QoL

背包按类型/品质/套装筛选 + 按评分排序（`scoreEquipment`）、tooltip 显示评分与"已穿 x/4"、单条词条可锁定不被重铸覆盖、强化面板显示成功率与加成来源、自动出售保护套装部件、批量出售套装前二次确认、状态栏显示当前称号与已激活套装。

### 2.8 英雄系统（收集 / 召唤 / 升星 / 编队 / 大招）

原版最大的手感缺口是「玩家不存在」：成长全在装备上，没有角色。新增 6 名英雄、4 个阵营：

| 英雄 | 阵营 | 稀有度 | 大招 |
| --- | --- | --- | --- |
| 艾登 · 晨刃 | 圣殿 | 4★ | 圣壁宣告：本场承伤 -X% |
| 薇尔莉特 | 秘法 | 5★ | 星陨术：立即造成 X% 每秒伤害 |
| 卡格斯 | 兽部 | 3★ | 血怒图腾：本场 DPS +X% |
| 莉安娜 | 兽部 | 4★ | 穿云一箭：无视护甲的爆发 |
| 莫德雷克 | 深渊 | 5★ | 血之契约：削减目标最大生命 |
| 纳格林 | 深渊 | 5★ | 龙焰吐息：伤害 + 回血 |

- **召唤**：30000 金币/抽，十连 270000；55/33/12 的稀有度权重，18 抽起软保底逐抽提高 5★ 概率、40 抽硬保底，每 10 抽保底一个 4★+；重复英雄自动转碎片（3★/4★/5★ → 6/10/20）。
- **养成**：升级（金币，上限随玩家等级）、升星（碎片 + 金币，属性 ×1.18/星）、大招强化（消耗**深渊回响**，把两套经济串起来）。
- **编队**：最多 3 人，基础攻击/生命/防御与被动词条全部汇入 `set_player_attribute` 的加成池（和装备同一入口，因此 `%` 加成对英雄属性同样生效）。
- **阵营共鸣**：2 人与满编（3 人）各一档，例如兽部满编 = 击杀后回复 3% 生命。
- **大招**：每场胜利 +1 充能，攒满自动释放（充能上限 2×消耗），面板上方有小队头像 + 充能点。`ULT_CAP` 给每类大招设了硬上限，避免"一个大招秒掉整个副本"。
- 深渊回响 ↔ 招募令 ↔ 英雄碎片可以互相兑换，形成「刷深渊 → 抽英雄 → 打更高难度」的循环。

### 2.9 战斗表现层

战斗原来是「图标平移 + 一行文字」。现在：

- 飘字：击杀伤害、承伤、吸血、金币、大招、暴击（`fx-num` 六种配色，纯表现层，不参与结算）。
- 受击闪白 + 暴击/大招震屏（`.fx-hit` / `.shake`），战斗舞台换成生成的场景图（`.dungeons::before` 叠 `arena.jpg`，28% 透明度保证图标仍可读）。
- 装备格加品质光框（`.q-frame` + `--qc`），独特/神话品质有脉冲光效。
- **速度 1x / 2x / 4x**：只缩放定时器间隔（`speedK`），不改变任何一次战斗的数值结果。

### 2.10 音效（零素材）

`src/assets/js/sfx.js` 用 WebAudio 振荡器 + 噪声合成点击、金币、命中、暴击、胜利、强化成功/失败、召唤、大招等 14 种短音，`sfxForSysInfo` 把系统信息流映射成声音（掉落/稀有掉落/战败各不同）。首次交互才创建 `AudioContext`，任何音频异常都被吞掉，绝不影响玩法；不引入一个音频文件。

### 2.12 章节远征（主线推进 / 星级 / 扫荡 / 体力）

挂机游戏缺一条「今天到底推进了什么」的主线。新增 12 章 × 5 关（`src/assets/config/campaign.js`），但**不自建数值表**：每一关的怪物直接由未改动的 `handle.createRandomDungeons` 在固定等级上取中位数导出（第 1 章 lv5、第 12 章 lv115），战斗仍然跑原版解析式竞速 `resolveBattle`，所以章节手感 = 原版手感。

| 规则 | 取值 |
| --- | --- |
| 星级 | 胜利且剩余生命 ≥80% → 3★，≥45% → 2★，其余 1★；败北 0★ |
| 体力 | 上限 120，挑战 -5，扫荡 -3；每 150 秒回 1 点，**按时间戳懒算**（离线也照回，不挂计时器） |
| 扫荡 | 先 3★ 通关才解锁；给 60% 金币 + 少量回响 + 30% 概率掉一件（不掉独特），不进战斗、不扣血 |
| 一键扫荡本章 | 一次把本章所有 3★ 关卡扫完（次数上限 `SWEEP.maxTimes`） |
| 首通 | 额外给英雄碎片 + 深渊回响（把主线接进 2.8 的召唤经济） |
| 掉落 | 3★ 多掷一次；章节首领 12% 出「独特」品质，其余场合不掷独特，避免白嫖毕业装 |
| 解锁 | 上一章 5 关全通才开下一章；关卡按顺序解锁 |
| 战败 | 血量被打到 **1 点**（与原版 `set_player_curhp('dead')` 的地板一致），不会卡死主世界进度 |

面板（`src/views/component/campaignPanel.vue`）在挑战前就把每个节点的胜负、击杀耗时、剩余生命百分比算出来摆在格子里（同一套 `resolveBattle`，所见即所赢），打完给一份战报（星级 / 击杀耗时 / 承受伤害 / 获得 / 掉落）。掉落直接复用四个部位面板的 `createNewItem` 与背包 `grid`，不另写一套生成器。

### 2.13 每日任务与签到

`src/assets/config/daily.js` + `src/views/component/dailyPanel.vue`：

- **每日 4 条任务**：从 14 条任务池里按「日期字符串哈希」抽取，同一天永远同一批（刷新/重开不会重置进度），隔天自动换一批。
- **按等级过滤 + 目标缩放**：每条任务有 `need`（最低开放等级），lv1 不会刷出「扫荡 10 次」「深渊 8 层」这种当天根本做不到的任务；目标量与金币奖励再按等级适度放大，描述里的数字用的是**放大后的实际目标**（大额自动折算成「万」）。
- **进度 = 当日增量**：任务只记 `{key, base, goal}`，读的是 `stats[key] - base`。统计项由 `store.report()` 统一埋点（召唤、强化、扫荡、章节星级、祭坛、出售…），所以任务不额外改任何玩法逻辑，也不会被历史累计污染。
- **奖励**：金币 = 系数 × 玩家等级 × 30，另有回响 / 碎片 / 招募令；支持单条领取与一键领取。
- **7 天签到**：断签回到第 1 天，第 7 天是厚礼（含招募令）；跨零点由面板的 1 秒 tick 与底栏红点共同兜住。
- **0 点滚动**：`index.vue` 每分钟 commit 一次 `daily_rollover`，挂机挂过午夜也会自动换任务，不需要重开。
- 与成就联动：累计签到天数解锁称号「坚守者」（`achievements.js` 的 `loyal`）。

### 2.14 新增存档字段与恒等性

`campaign`（星级表 / 首通表 / 体力与时间戳 / 统计）与 `daily`（当日任务表 / 签到状态）随 `ex` 一起落盘。两套系统在**未使用时完全恒等**：不清零任何属性，`stars` 为空时章节不提供任何加成，因此老存档导入后行为与原版一致（`npm run fidelity` 第 6 项即在守这条线）。

## 3. 存档兼容性

`_sd` / 导入导出仅**新增** `ex` 字段（`title`、`unlockedAchievements`、`stats`、`settings`、`abyss`、`heroes`、`campaign`、`daily`、`ultCharge`、`t`）。英雄读档时会过一遍 `normalizeHeroes`：未知 id 丢弃、缺失字段补默认、星级/技能钳制到合法区间，脏存档不会把面板搞崩。旧存档导入时缺字段一律走默认值，行为与原版一致；新存档拿到旧版本也能读出装备/金币/转生部分。

# 游戏设计

- 通过副本获得装备与金币
- 装备分为四个等级：破旧、普通、神器、史诗
- 主角默认每秒回血 2%
- 默认暴击伤害 150%
- 完成副本时可能掉落独特级别(5 个词条)的装备（通关后 2.5%掉落率，无尽挑战不会掉落）
- 通关后开启无尽挑战
